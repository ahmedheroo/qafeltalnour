# المساعد الذكي — قافلة النور (AI Chatbot)

شات بوت عربي عائم في الموقع يجيب على أسئلة الزوار عن الشركة والخدمات، مدعوم بـ **Cohere** (cohere.com) — ويعمل بالكامل على **GitHub Pages** (بدون أي سيرفر).

## الملفات

| الملف | الوظيفة |
|---|---|
| `api/chat.js` | "عقل" المساعد — يستدعي Cohere مباشرة من المتصفح ويعيد الرد بالعربية |
| `api/config.sample.js` | قالب إعداد مفتاح Cohere |
| `api/config.js` | مفتاحك الحقيقي (مستثنى من Git — يُولَّد تلقائياً أثناء النشر) |
| `assets/js/chat-widget.js` | واجهة الشات (زر عائم + نافذة المحادثة) |
| `assets/css/chat-widget.css` | تنسيقات الواجهة (أخضر الهوية #0a7f11) |
| `.github/workflows/deploy.yml` | نشر تلقائي إلى GitHub Pages + حقن المفتاح من السر |

## إعداد مفتاح API (سر بيئي)

المفتاح **لا يُكتب في أي ملف داخل المستودع** — يُحقن وقت النشر من GitHub Secrets:

1. اذهب إلى مستودعك على GitHub → **Settings → Secrets and variables → Actions**.
2. اضغط **New repository secret** (أو أضفه كـ Environment secret على بيئة `github-pages`).
   - الاسم: `COHERE_API_KEY`
   - القيمة: مفتاحك من https://dashboard.cohere.com/api-keys
3. عند كل Push إلى `main` سينشر الـ workflow الموقع ويولّد `api/config.js` تلقائياً من السر.

### محلياً (اختبار بدون نشر)
```
cp api/config.sample.js api/config.js
```
ثم ضع المفتاح داخل `api/config.js` (الملف مستثنى من Git ولن يُرفع أبداً).

> ℹ️ بدون مفتاح يعمل المساعد في **وضع العرض التوضيحي**: ردود جاهزة مفيدة بدون Cohere — الموقع لا ينهار أبداً.

## كيف يعمل

1. الزائر يكتب سؤاله في نافذة الشات العائمة (أسفل يمين الموقع، فوق زر الواتساب).
2. `chat-widget.js` يمرر السؤال + آخر 20 رسالة إلى `QNChat.getReply()` في `api/chat.js`.
3. `api/chat.js` يبني "برومبت نظام" بالعربية يحتوي كل معلومات الموقع (الباقات، الفنادق، الباصات، أوقات العمل، العنوان، الواتساب) ويستدعي نموذج `command-a-03-2025` من Cohere مباشرة.
4. الرد يعود بالعربية ويظهر في النافذة. عند فشل Cohere يُرسل رد بديل يوجه العميل للواتساب.

### الحماية المدمجة
- المفتاح خارج المستودع تماماً (Secret بيئي في GitHub).
- حد محلي للرسائل: 15 رسالة / 5 دقائق لكل زائر (localStorage) — يبطئ أي إساءة.
- تنظيف وتقصير المدخلات (الرسالة ≤ 1000 حرف).
- ردود بديلة تلقائية عند أي فشل — الزائر لا يرى خطأً.

### ⚠️ ملاحظة أمنية مهمة
أي مفتاح يُستخدم في المتصفح يظهر لمن يفتح DevTools؛ هذه طبيعة المواقع الثابتة. للحماية:
- ضع **سقف إنفاق (spending limit)** على حسابك في لوحة Cohere.
- راقب الاستخدام من لوحة Cohere وأعد توليد المفتاح إذا لاحظت استهلاكاً غريباً.
- حد الرسائل المدمج يقلل من إساءة الاستخدام لكنه ليس حماية مطلقة.

## تخصيص معلومات المساعد

عدّل الكائن `KB` في أعلى `api/chat.js` — هذه هي "معرفة" المساعد. أضف مثلاً أسعاراً ثابتة أو شروطاً جديدة، وسيعرفها فوراً.

## النشر

Push إلى `main` → يعمل الـ workflow تلقائياً وينشر إلى GitHub Pages. تأكد فقط أن Pages مضبوط على **Source: GitHub Actions** من Settings → Pages.
